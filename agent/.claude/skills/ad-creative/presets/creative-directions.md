# Creative Direction Templates

Use these as starting points when proposing 2-3 creative directions to the user.

## Traditional Elegance
- **Tone:** Formal, heritage, premium
- **Colors:** Gold, deep tones, warm lighting
- **Typography:** Elegant, serif-inspired, script prominence
- **Copy style:** Pure native language, respectful, classical references
- **Best for:** Jewelry, silk sarees, sweets, puja items, wedding-related
- **Festival match:** Diwali, Navratri, Onam, Durga Puja

## Modern Festive
- **Tone:** Youthful, energetic, social-media-native
- **Colors:** Vibrant, high contrast, trending palettes
- **Typography:** Bold sans-serif, mixed language (Hinglish/Tenglish/Tanglish)
- **Copy style:** Code-mixed language, casual, emoji-friendly
- **Best for:** Electronics, fashion, beauty, food delivery, D2C brands
- **Festival match:** Holi, New Year, sale events

## Bold Sale / Urgency
- **Tone:** Direct, urgent, deal-focused
- **Colors:** Red, yellow, bright orange (urgency colors)
- **Typography:** Extra bold, large discount numbers, "SALE" badges
- **Copy style:** Short, punchy, numbers-first ("FLAT 50% OFF!")
- **Best for:** Flash sales, clearance, competitive pricing, e-commerce
- **Festival match:** Generic sale, any festival with commercial angle

## Emotional / Storytelling
- **Tone:** Warm, family-oriented, gifting context
- **Colors:** Soft, warm, inviting
- **Typography:** Clean, readable, message-first
- **Copy style:** Narrative, relationship-focused ("Gift them something special")
- **Best for:** Festival gifting, premium brands, family-oriented products
- **Festival match:** Diwali, Raksha Bandhan, Christmas, Eid

## Minimalist / Premium
- **Tone:** Sophisticated, understated luxury
- **Colors:** Black, white, gold accents, single accent color
- **Typography:** Thin, elegant, lots of whitespace
- **Copy style:** Minimal text, brand-name-forward, less is more
- **Best for:** Luxury brands, high-end jewelry, premium electronics
- **Festival match:** Any (the restraint signals premium)
